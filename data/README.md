# Data

Raw and processed datasets are intentionally excluded from this repository.

The experiments use Free Spoken Digit Dataset, Google Speech Commands v0.02,
and the MIMII industrial sound dataset. Obtain each dataset from its official
source and follow its corresponding license and usage terms. The project
README documents the expected local paths and download or inspection commands.

Do not commit audio archives, extracted recordings, processed copies, or other
dataset-derived files to this repository.
